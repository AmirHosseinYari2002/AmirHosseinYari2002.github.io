Progress

Enter the admin key (from the Apps Script execution log of setup, or Project Settings → Script Properties → ADMIN_KEY) and press Load progress.

Agreement

Recomputed on every Load progress / refresh from the windows both annotators have submitted (drafts are not used), so the numbers grow window by window. Unit: one segment. 95% intervals: percentile bootstrap over windows (2,000 resamples, seed 20261115), because segments of one window are not independent. Primary statistic: Krippendorff's α (nominal); a segment flagged without a label is missing for that annotator.

Judges Load the judge files written by taskB_judge_labeling.ipynb (TaskB/judges/*.json) and, for the per-model claim J2 and the strata, TaskA/private/key.csv. They are read and kept only in this browser, never uploaded or published.

Annotators

Only these email addresses can sign in. The list is ANNOTATORS at the top of backend/Code.gs; to change it, edit the list and deploy a new version. Block keeps one of them out without deleting their data; Allow undoes it.

Workload & cost estimate

Planning figures from the windows in traces.js. Each window's time = words of window text ÷ reading speed + segments × seconds per label + words to read only (problem and grey context) ÷ context reading speed + a fixed overhead for flags, review and submit. Change any assumption; values are remembered in this browser. Once annotators have submitted windows, their observed speed appears below and can replace the assumption.
