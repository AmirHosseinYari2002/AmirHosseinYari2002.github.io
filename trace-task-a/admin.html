One file per annotator slot, in the format of platform/export_format.md: study windows only, submitted only, CUTs as character offsets in window_text, flags as {offset, note}, active seconds. Save the files as TaskA/annotations/A1.json, A2.json, … and run Part B.

Annotators

The slot decides the annotator's window order (assignments.json) and the name of their export file. Each slot can have one active annotator. Annotators sign in with the email registered here; deactivating keeps their data.
