Agreement (live)

Inter-annotator and human–LLM agreement, recomputed from the submitted windows every time this page loads or refreshes. The code is a line-by-line port of Part B of taskA_human_validation.ipynb (same units, metrics, tolerance, preregistered thresholds; checked against the notebook to floating-point precision). Only the bootstrap intervals and the chance floor use a different random-number generator, so they can differ from the notebook in the third decimal. Report the numbers Part B prints. Until every annotator has submitted every window, everything here is provisional and computed on the windows that all selected annotators have submitted: every metric appears from the first such window, while bootstrap intervals, p-values and the preregistered verdicts appear from the second (one window cannot give an interval).

Export for Part B

One file per annotator slot, in the format of platform/export_format.md: study windows only, submitted only, CUTs as character offsets in window_text, flags as {offset, note}, active seconds. Save the files as TaskA/annotations/A1.json, A2.json, … and run Part B.

Annotators

The slot decides the annotator's window order (assignments.json) and the name of their export file. Each slot can have one active annotator. Annotators sign in with the email registered here; deactivating keeps their data.
